| File | Topic |
|---|---|
| Topic02_VariablesAndConstants.swift | Variables and Constants |
| Topic03_OperatorsAndExpressions.swift | Operators and Expressions |
| Topic04_Collections.swift | Swift Collections |
| Topic05_EnumsStructsClasses.swift | Enumerations, Structures and Classes |
| Topic06_Optionals.swift | Optionals and Optional Handling |
| Topic07_ARC.swift | ARC and Memory Management |
| Topic08_Functions.swift | Functions |
| Topic09_Closures.swift | Closures and Higher-Order Functions |
| Topic10_ProtocolsAndExtensions.swift | Protocols and Extensions |
| Topic11_GenericsAndErrors.swift | Generics and Error Handling |
| Topic12_IntegratedProgramming.swift | Integrated Swift Programming |

Written answers (compiler errors, predictions, explanations) are in NOTES.md.

## Run

```
swift Topic02_VariablesAndConstants.swift
```

Or paste a file into an Xcode Playground.
